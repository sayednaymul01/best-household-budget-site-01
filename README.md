Ghorer Hisab is a household budget site for a family of four in Dhaka. It tracks monthly income against spending by category, follows six months of income, spending and savings, keeps savings goals with live progress, and sums it all up in reports with charts — all from static files, offline, on desktop and on a phone. The sample household earns about ৳85,000 a month, spends about ৳58,000, and saves the rest towards an emergency fund, the children's education and the next festival.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then open `out/app/index.html` in a browser, or serve `out/app/` with any static server. The site needs no network: add income or an expense, switch months, contribute to a goal or change a budget and every total, bar and chart updates at once. Entries are kept in the browser's local storage; the footer link restores the sample household.
